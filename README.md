# Планировщик автомобильных маршрутов

В браузере можно ввести два названия городов России или выбрать их из подсказок. Для одноимённых городов выберите вариант с нужным регионом. После нажатия «Построить маршрут» программа покажет выбранный вариант, схему, расчётное время, расстояние и расход топлива. Если сервис вернул альтернативы, они появятся в таблице.

Учебный сценарий Клин → Тверь расположен ниже. Он сравнивает бесплатную М-10, платную М-11 и смешанный маршрут с выездом на М-11 у Завидова. Программа выбирает маршрут и время выезда по расходу топлива, прямым расходам, времени в пути или расходам с денежной оценкой времени. При заданном сроке прибытия опаздывающие поездки исключаются из выбора.

## Запуск

Нужен Python 3.10 или новее. Используется стандартная библиотека. Скачайте ветку целиком. Для запуска нужны `route_planner.py`, `route_planner_web.html`, `city_routing.py` и `russian_cities.csv` в одной папке.

```bash
python3 route_planner.py
```

Откроется браузер с формой и таблицами. Расчёт выполняет локальный Python-сервер. Если вкладка не открылась автоматически, откройте адрес `http://127.0.0.1:…/`, который напечатан в Терминале. Оставьте окно Терминала открытым на время работы. Для остановки нажмите **Control+C**.

Для запуска расчёта в Терминале:

```bash
python3 route_planner.py --cli
python3 route_planner.py --objective fuel
python3 route_planner.py --start 07:30 --end 09:00 --deadline 09:15
python3 route_planner.py --objective score --price 65 --value-of-time 400 --all
python3 route_planner.py --help
```

По умолчанию программа проверяет окно 07:30–09:00 МСК с шагом 15 минут от начала окна и включает его конец. Для сравнения при одном времени выезда укажите одинаковые значения `--start` и `--end`. Срок `--deadline` относится к дню выезда. Флаг `--all` выводит каждую проверенную поездку.

## Маршрутизация между городами

- Справочник хранится локально. В `russian_cities.csv` оставлены название, регион и координаты центра из набора DaData / HFLabs. Справочник содержит 1 117 записей. [Исходные данные](https://github.com/hflabs/city/blob/master/city.csv) · [Лицензия данных CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).
- Для маршрута нужен интернет. Сервер отправляет координаты двух городов в OSRM / FOSSGIS и сравнивает возвращённые варианты. По умолчанию выбирается минимальное время в пути. Расстояние и топливо оптимизируются среди вариантов, возвращённых OSRM. Если альтернатив нет, показывается один маршрут. [Документация OSRM](https://project-osrm.org/docs/) · [Сервис FOSSGIS](https://routing.openstreetmap.de/about.html) · [Данные OpenStreetMap](https://www.openstreetmap.org/copyright).
- Расход оценивается по средней скорости и модели автомобиля для ровной дороги. В этом режиме отсутствуют данные о текущих пробках, тарифах и времени выезда. Российский справочник ограничивает выбор начального и конечного города. Сам маршрут может проходить через другую страну.
- Адрес совместимого сервера OSRM можно задать через `ROUTE_PLANNER_OSRM_URL`. Он должен включать префикс до `/route/v1/driving`. По умолчанию используется `https://routing.openstreetmap.de/routed-car`.

## Методика для Клина и Твери

Расход в движении рассчитывается по коэффициентам `FuelCoeffs.from_vehicle(VehicleParams())` из первой лабораторной при нулевом ускорении. Задержки добавляют расход на холостом ходу 0,6 л/ч. Если режим трафика меняется в пути, остаток участка пересчитывается с новой скоростью и задержкой. Прямые расходы равны стоимости топлива и проезда. Критерий `score` дополнительно учитывает оценку часа, умноженную на время в пути. [Исходная модель ТС](https://github.com/tokarevakate/vehicle-route/blob/main/webapp/consumption_model.py)

Длины, уклоны, скорости и задержки заданы для учебного эксперимента. Плата 140 ₽ и 370 ₽ взята из фиксированной таблицы для I категории ТС и сценария понедельника — четверга. [Тарифы сценария](https://avtodor-tr.ru/upload/iblock/613/eqvqrtjua5p4qquk3n94k9e8g0jdhvq1.pdf) · [Развязки М-11](https://unitoll.ru/roads/m-11/objects_m11/traffic_junctions/)
